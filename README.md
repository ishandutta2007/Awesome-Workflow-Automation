# Top Workflow Automation Tools Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on No-Code/Low-Code Automation, Integration Platforms (iPaaS), Triggers & Actions, and Orchestration*  
**Last updated: August 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Workflow Automation**. These tools connect apps, trigger actions on events, orchestrate multi-step processes, and eliminate repetitive manual work across business and technical systems.

**Examples** include Zapier, Make, n8n, Workato, Tray.io, Microsoft Power Automate, Pipedream, Integrately, Albato, and Activepieces (the category leaders).

**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosted workflow automation, visual builders, script-based orchestration, and integration platforms — ideal for teams that want unlimited executions, full data control, and no per-task pricing.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms

- **[Zapier](https://zapier.com/)**  
  The most widely known no-code automation platform with thousands of app integrations, multi-step Zaps, and a massive ecosystem for business users.

- **[Make](https://www.make.com/)** (formerly Integromat)  
  Visual scenario-based automation platform offering advanced data transformation, routers, and complex multi-app workflows with a strong free tier.

- **[n8n Cloud](https://n8n.io/)**  
  Hosted version of the popular workflow automation tool with a node-based editor, extensive integrations, and both no-code and code capabilities.

- **[Workato](https://www.workato.com/)**  
  Enterprise-grade iPaaS and automation platform focused on business process automation, AI-assisted recipes, and complex enterprise integrations.

- **[Tray.io](https://tray.io/)**  
  Low-code automation and integration platform designed for scalable, API-first workflows and enterprise connectivity.

- **[Microsoft Power Automate](https://powerautomate.microsoft.com/)**  
  Deeply integrated Microsoft 365 and Azure automation service supporting cloud flows, desktop RPA, and AI Builder capabilities.

- **[Pipedream](https://pipedream.com/)**  
  Developer-friendly workflow platform with code-first steps, event sources, and generous free tier for API and serverless automation.

- **[Integrately](https://integrately.com/)**  
  Affordable one-click automation platform positioned as a simpler, lower-cost alternative to Zapier with many pre-built integrations.

- **[Albato](https://albato.com/)**  
  No-code automation and integration tool popular for connecting SaaS apps with flexible pricing and growing connector library.

- **[Activepieces Cloud](https://www.activepieces.com/)**  
  Hosted offering of the open-source Activepieces platform, providing visual automation with AI and MCP support.

## Open-Source GitHub Projects

- **[n8n](https://github.com/n8n-io/n8n)**  
  Leading source-available workflow automation tool with a powerful visual node-based editor, 400+ integrations, JavaScript/Python code nodes, and full self-hosting support. Extremely popular Zapier alternative.

- **[Activepieces](https://github.com/activepieces/activepieces)**  
  Fully open-source (MIT) Zapier-style automation platform with a modern UI, growing piece library, AI agent support, and MCP server capabilities. Excellent for self-hosting with no execution limits.

- **[Windmill](https://github.com/windmill-labs/windmill)**  
  Open-source developer-oriented platform for scripts, workflows, and internal tools. Supports Python, TypeScript, Go, and SQL with auto-generated UIs and strong orchestration features.

- **[Automatisch](https://github.com/automatisch/automatisch)**  
  Open-source no-code workflow automation tool designed as a self-hosted Zapier alternative with a familiar trigger-action model and Docker-friendly deployment.

- **[Huginn](https://github.com/huginn/huginn)**  
  Classic open-source system for building agents that monitor the web, watch for events, and take automated actions — highly flexible event-driven automation.

- **[Node-RED](https://github.com/node-red/node-red)**  
  Flow-based programming tool for event-driven applications, especially strong in IoT, hardware, and real-time data pipelines, with a large node ecosystem.

- **[Temporal](https://github.com/temporalio/temporal)**  
  Open-source durable execution and workflow orchestration platform for mission-critical, long-running, and reliable business processes (code-first).

- **[Apache Airflow](https://github.com/apache/airflow)** & **[Kestra](https://github.com/kestra-io/kestra)**  
  Open-source workflow orchestration platforms primarily used for data pipelines but also applicable to broader automation and scheduling use cases.

### Additional Strong Open-Source Options

- **Actionsflow** — GitHub Actions-based or self-hosted Zapier/IFTTT-style automation.
- **StackStorm** — Event-driven automation and auto-remediation platform.
- **Prefect** and other modern data-oriented orchestrators that support general workflows.
- **Custom agent frameworks** and LLM-powered automation pipelines.
- Many community nodes, pieces, and extensions that expand the capabilities of n8n and Activepieces.

**Frameworks for building custom systems**: Start with **Activepieces** (MIT, simplest Zapier-like experience) or **n8n** (most integrations and maturity) for visual automation. Use **Windmill** when you prefer scripts-as-workflows, **Temporal** for durable long-running processes, and **Node-RED** or **Huginn** for event-driven or IoT-style automation. Combine them as needed.
